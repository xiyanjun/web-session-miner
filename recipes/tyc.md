# 天眼查站点适配器（tyc）

> 目标站点：天眼查（www.tianyancha.com）。满足「MCP + 网页版并存」：官方 MCP `tyc-mcp`
> 按次扣积分，网页版 VIP 会员可无限查看。

## 1. 站点与登录态

- **站点名**：天眼查（tianyancha.com）
- **入口 URL**：`https://www.tianyancha.com/`
- **登录态确认方式**：首页右上角出现「登录/注册」即**未登录**；已登录则显示用户头像/昵称。
- **会员类型**：VIP（网页版会员）。官方 MCP `tyc-mcp` 为按次积分计费，VIP 不含 API 额度。

> ⚠️ **硬前置（与企查查的关键差异）**：天眼查**搜索即强制登录**——未登录访问
> `https://www.tianyancha.com/search?key={关键词}` 会 302 重定向到
> `https://www.tianyancha.com/login?from=...`。因此**必须先登录**才能抓取，无法像企查查
> 那样未登录预搜索。登录方式为**扫码**（微信 / 小程序二维码）。

## 2. URL 规律

- **搜索页 URL**：`https://www.tianyancha.com/search?key={关键词}`（关键词 URL 编码；需登录）
- **企业详情页 URL**：`https://www.tianyancha.com/company/{数字ID}`（**待登录后实证确认**）
- **人物（老板）详情页 URL**：待登录后确认（推测 `/human/{id}` 或类似）
- ⚠️ 详情页 ID 规律暂未实证，首次使用需登录后从搜索页提取真实 href。

## 3. 字段定位（DOM）

- ⚠️ **待登录后实证**：未登录无法进入详情页，DOM 结构尚未侦察。
- 预期可复用企查查的定位思路：`document.body.innerText` 全文本 + 关键词切片定位
  （股东/主要人员/对外投资等表头关键词）。

## 4. 歧义 / 同名甄别

- 与企查查同类风险：同名企业/人物需交叉验证（简介 + 归属 + 舆情）。

## 5. 反爬 / 风控

- **登录门槛高**：搜索强制登录，登录态过期需重新扫码。
- **验证码风险**：批量抓取可能触发滑块/验证码，需控制频率。

## 6. 备注
